## Screenshot Requirements

### General Guidelines:
- **Resolution:** Minimum 1920x1080 or higher
- **Format:** PNG format preferred for clarity
- **File Naming:** Use the exact filenames listed above
- **Location:** Save all screenshots to `doc-screenshots/` directory
- **Browser:** Use Chrome browser for consistency
- **Theme:** Use default theme unless specified otherwise

### Specific Requirements:
- **Overlays:** Show overlays on actual web pages (not blank pages) for context
- **Modals:** Capture modals when they're open and fully visible
- **Settings:** Show relevant sections expanded/highlighted
- **UI Elements:** Ensure buttons, toggles, and controls are clearly visible
- **Annotations:** No need to add arrows or annotations - the screenshots should be self-explanatory

### Tips:
- Use a clean browser window (minimize extensions/toolbars)
- Ensure good contrast and visibility
- Capture at full resolution, the docs will resize as needed
- Test that screenshots look good on both light and dark backgrounds
- Remove any sensitive information (API keys, personal data) before capturing

---

## Replacement Instructions

After taking all screenshots:

1. Save each screenshot with the exact filename listed above
2. Place all files in the `doc-screenshots/` directory
3. The placeholders in `docs.html` will automatically display the images once the files exist
4. Verify all screenshots display correctly in the documentation
5. Check that images are properly sized and readable
