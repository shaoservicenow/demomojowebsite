What would you like to record?
Select Window Size
Selecting a device fills the size fields. Rotate by swapping width/height.
Note: "Current Size" keeps your window as is. Other options will resize before recording starts.

Tip: When recording tabs, Chrome shows a "Sharing this tab to DemoMojo" bar that reduces visible content area (~40px). This is normal and Chrome handles it automatically.
Full Screen Recording: Your entire desktop will be captured. No window resize is needed. Chrome will show you exactly what will be recorded.
Microphone Audio
Note: Chrome will ask for permission to use your microphone when you start recording.
Recording Quality
Higher framerate/bitrate increases file size. 30 fps / 2.5 Mbps is a good default.
